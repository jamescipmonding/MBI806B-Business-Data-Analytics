# Project Overview

This project was completed as part of the **Master of Business Informatics & Analytics (MBI806B)** and focuses on applying practical business data analytics techniques to support insight-driven decision-making.

Rather than purely theoretical modelling, the project emphasises real-world analytics workflows that mirror industry practice, including data preparation, analysis, and communication of insights.

---

## Business Context

Organisations increasingly rely on data to guide operational and strategic decisions.  
This project demonstrates how raw datasets can be transformed into structured information and meaningful insights that decision-makers can interpret and act upon.

The analysis approach prioritises:
- Clarity of insights  
- Business relevance  
- Transparency of analytical steps  

---

## Project Objectives

The key objectives of this project were to:

- Prepare and structure raw data for analysis  
- Apply SQL for data extraction and analytical querying  
- Use Python for analytical processing and derived metrics  
- Communicate findings through clear visualisations and summaries  

---

## Expected Outcomes

By completing this project, the following outcomes were achieved:

- Identification of patterns and trends within the dataset  
- Translation of analytical results into business-oriented insights  
- Demonstration of an end-to-end analytics workflow aligned with industry expectations
